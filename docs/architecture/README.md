# Architecture

The current implementation is a locally runnable Python support engine with
optional AWS integrations. The target is a disposable serverless AWS
application with a static React client, asynchronous chat processing, managed
retrieval, persistent sessions and tickets, and Cognito-protected operator APIs.

The root README contains the canonical current and planned diagrams. A component
moves from planned to implemented only after local checks pass, and from
implemented to deployed only after live verification.
